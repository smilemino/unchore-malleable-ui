Ask any AI for a screen that uses ui.render(html, css), ui.onAction(fn), ui.load(key) and ui.save(key, value). Paste it here.

Test-run firstA new screen runs hidden for 1.5 seconds. It is shown only if it draws and keeps answering.
No network, no cookiesThe screen's code runs in a worker inside an opaque-origin iframe with connect-src 'none'.
Only safe tagsScripts, links, images, forms and on* handlers are stripped before drawing.
Always a way backThe reset button lives outside the sandbox. A screen that freezes is stopped and the old one stays.

In this demo the edits are pre-written, so it works without an AI. In Unchore an AI writes them from whatever you say, and your screen is saved to your account. Source: github.com/smilemino/unchore-malleable-ui
